### 🟠 **Sentinel**
An **AI-supervised containerized development environment**
- Docker-based isolated workspace enabling safe, reproducible experimentation
- Automated workspace provisioning and container lifecycle management
- AI-powered monitoring agent observing developer actions, tool usage, and system requests
- Generates activity reports, execution traces, and safety insights for AI-assisted development

---

### 🟢 **MIRA_C**
An **agent-based automotive fault detection system**
- Identifies vehicle anomalies in real time via computer vision
- Built with OpenCV for visual fault identification
- Applies regression and classification models for diagnostic routing

---

### 🟣 **Transformer-Based Indian Sign Language Recognition**
A **deep learning research project** in computer vision
- Transformer-based image classification trained on the Kaggle ISL dataset
- Achieved **85% classification accuracy** using transfer learning, augmentation, and optimization
- Documented experimentation and benchmarking using PyTorch

---

### 🔴 **AbiLang**
A **custom interpreted programming language**, built from scratch in Python
- Complete language pipeline: lexical analysis, recursive-descent parsing, AST generation, runtime interpretation
- Supports functions, recursion, conditionals, loops, custom error handling, and an interactive REPL
- Includes CLI tooling, automated tests, and standalone executable packaging for `.abi` programs
